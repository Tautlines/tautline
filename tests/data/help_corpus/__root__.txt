Minervit AI Delivery Methodology CLI.

positional arguments:
  {version,install-cli,uninstall-cli,sync-methodology,render-adapters,validate-adapter,public-contract,public-release-check,public-release-export,registry-package,release-tail,release-drift-check,secret-status,cut-release,init-project-adapter,methodology-status,decision-record,lane-status,builder-token,lane-role,builder-env,github-budget-status,stakeholder-question,decisions-report,event-log-path,event-tail,event-rotate,inbox,slim,backlog,board,issue,debt,doctor,red-green-check,init,builder-guard,work,evidence,health}
    version             Print plugin version, methodology repo commit, and
                        local-vs-remote sync status.
    install-cli         Install the CLI shim + methodology.env; mutates
                        ~/.local/bin and ~/.config/minervit.
    uninstall-cli       Remove the installed CLI shim and methodology.env
                        (reverses install-cli).
    sync-methodology    Update the methodology repo (optional auto-rescue),
                        install guards, and report version/remote status.
    render-adapters     Render CLAUDE.md/AGENTS.md/lane config from a project
                        adapter (--write/--check) with drift guards.
    validate-adapter    Validate a project adapter JSON file against the
                        adapter schema (reports all violations).
    public-contract     Generate/check the public compatibility contract
                        manifest for commands, adapter keys, generated files,
                        skills, and policy modules.
    public-release-check
                        Fail if the checkout still contains private adapters,
                        private product references, account IDs, or live
                        adapter hosts.
    public-release-export
                        Create a clean git repository candidate for public
                        release, then run public-release-check against it.
    registry-package    Generate a registry package tree: the real PyPI
                        package (wrapper + embedded tree + stamped snapshot
                        manifest) or the npm namespace pointer (one source of
                        truth for the registry copy).
    release-tail        Run the whole release tail: public export, fast-
                        forward mirror commit, tag, GitHub Release, registry
                        publish, drift check.
    release-drift-check
                        Report the repo, npm, and PyPI versions and fail when
                        any surface has drifted.
    secret-status       Report WHERE a named secret is reachable from (process
                        env, config env, secrets file) without printing its
                        value; exit 1 only when it is absent from all three.
    cut-release         Build the release boundary for the current VERSION:
                        checksums manifest + the signed-tag command (no git
                        mutation by default).
    init-project-adapter
                        Scaffold a new repo-local project adapter at
                        .tautline/adapter.json and print
                        bootstrap/render/start next steps.
    methodology-status  Report plugin version, lock state, adapter/plugin-
                        version drift, and lane state paths.
    decision-record     Write a machine-local structured decision-ledger entry
                        (works with narration off).
    lane-status         Report lane currency (branch/upstream/version drift).
                        Report-only; never blocks.
    builder-token       With --print, write the builder lane's GitHub token (a
                        cached GitHub App installation token); with --status,
                        prove its scope without printing it. One of the two is
                        required -- there is no default, because the default
                        would be a credential. Plain REST against
                        api.github.com.
    lane-role           Mark this checkout as a builder lane, return it to
                        human, or report which marker decided the role. Writes
                        .ai-work/lane-role; humans are never builders by
                        default.
    builder-env         Print the shell snippet a BUILDER lane evals to take
                        on the builder role, token and guard shim. Prints
                        only; a human never evals it. See docs/builder-
                        lanes.md.
    github-budget-status
                        Report GitHub REST/GraphQL rate-limit budget, cache
                        health, and (with --identity) this lane's identity.
                        Plain REST, never Projects GraphQL. Always exits 0: an
                        unreachable API is a printed finding, not a failure.
    stakeholder-question
                        Post (ask) or report (list) a tagged clarification
                        question as a GitHub issue/PR comment. Plain REST, no
                        project adapter. No board/label sync, no --strict, no
                        answered write-back -- `list` infers open vs answered
                        from later replies every time it runs, never stores
                        the verdict.
    decisions-report    Read surface over the decision ledger: filter by
                        time/reversibility/text; table or --json (read-only).
    event-log-path      Print the human and JSONL event log paths plus the
                        event-tail command hint.
    event-tail          Print the last N lines of the lane's human-readable
                        event log.
    event-rotate        Rotate the human and JSONL event logs when over size
                        (or always with --force).
    inbox               Pending operator decisions, explicit answers, and
                        resume acknowledgements.
    slim                Migrate an adapted project to the lean profile:
                        archive its process artifacts, remove the framework's
                        hooks, rewrite its config to lean-1, and render the
                        thin adapter. Never deletes; --dry-run shows the plan.
    backlog             Read and move this project's backlog:
                        list|add|take|done, against the provider its config
                        names (local queue file, GitHub issues, or Jira).
                        Nothing syncs.
    board               Read the product board (GitHub Projects):
                        list|show|fields. Read-only -- there is no verb here
                        that moves a card, because the board's order is the
                        director's statement.
    issue               Read and comment on the board repo's issues:
                        show|comments|find|comment. The only writes are
                        comments -- never a label, a state or an assignee.
    debt                File technical debt as a labelled issue -- and NOTHING
                        else: no assignee, no milestone, and never on the
                        product board.
    doctor              Four advisory checks -- branch-liveness, framework-
                        staleness, skip-lint, and --watch'd monitor-liveness:
                        each prints OK, FINDING, or UNKNOWN(reason). Always
                        exits 0; a finding is reported, never enforced.
    red-green-check     Mutate one symbol of --file and run --test-command
                        against it: report killed/survived/inconclusive. The
                        file is always restored. Report-only -- always exits
                        0.
    init                Interactive setup interview (<=8 questions; every
                        question also has a flag) that writes a lean
                        .tautline.json, validates it, and renders
                        CLAUDE.md/AGENTS.md. Refuses to overwrite an existing
                        config without --force.
    builder-guard       Keep BUILD AGENTS off GitHub issues and the project
                        board except through `tautline board|issue|debt`. A
                        no-op for humans: it engages only when
                        builder_role_active() says builder, and the default is
                        human.
    work                Declare work and see local or Git-shared peers
                        (advisory).
    evidence            Record an explicit command once or inspect its
                        receipt. No gates.
    health              Advisory integration and CI snapshot; local unless
                        --remote is given.

options:
  -h, --help            show this help message and exit
