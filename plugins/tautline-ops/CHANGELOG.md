## 0.6.151 - 2026-07-04

Iteration-review renderer dependencies now stay out of the plugin tree.

- **Setup uses user state.** `iteration-review-renderer-setup` copies the
  renderer kit to `~/.local/state/minervit/renderer-kit/` and installs
  dependencies there.
- **Plugin packaging stays small.** `node_modules`, generated videos,
  screenshots, posters, clips, and build output are ignored under
  `renderer-kit/`.
- **Existing adapters keep working.** No generated adapter migration is
  required; video-producing lanes just run the setup command before rendering.

## 0.6.150 - 2026-07-04

Delivery-specific operational skills moved out of the reusable methodology core.

- **Ops skills are packaged separately.** Iteration reviews, milestone updates,
  runtime event evidence, session journals, usage accounting, and database
  migration collision repair now live under `plugins/minervit-delivery-ops/`.
- **Core stays focused.** The main methodology plugin keeps reusable planning,
  review, guard, lifecycle, backlog, coordination, and adapter skills.
- **History is preserved.** The split uses path moves so the existing skill
  content remains intact for this phase.
